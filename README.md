Разработан интернет-магазин с адаптивным дизайном, тёмной темой, корзиной (localStorage, изменение количества, удаление), избранным, поиском, выезжающими слайдами (меню, каталог, профиль, поддержка и др.). Реализована регистрация пользователей (Flask + SQLite) с валидацией и flash-сообщениями. Добавлены карточки товаров с выбором размера, отзывами и рейтингом. Вёрстка соответствует методичке (семантические теги, CSS-переменные, БЭМ, медиа-запросы для мобильных устройств).
